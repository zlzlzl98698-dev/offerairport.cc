## 核心评测结论（Answer-First）

**如果你不需要折腾 Clash 分流规则、不依赖 OpenWrt 软路由，且希望用相对适中的月付成本获得 IPLC 专线与原生 IP 出口，Firefly 萤火虫属于值得月付试水的候选品牌；但如果你习惯把所有节点收拢到第三方通用客户端，或者追求先看独立晚高峰测速截图再下单，它并不符合你的筛选标准。**

在核对本地全部品牌档案后，本站将 Firefly 归类为「特征鲜明但证据边界清晰」的品牌——它具备**免翻墙直达官网**、**原生 IP（含香港、新加坡、日本、美国）**以及**非晚高峰美线 30Mbps** 的亮点，同时也存在**无第三方订阅**、**无 2026-08-11 独立测速截图**与**历史记录两次重复建档**的客观局限。完整品牌参数卡片与横向排位可对照[Firefly 品牌档案页](/brands/firefly/)、[品牌数据库总览](/brands/)及[主流核心机场对比总表](/airport/#core-candidates-table)。

## 二、IPLC 专线架构、原生 IP 与专属客户端的取舍

Firefly 在产品设计上走了一条「强线路、收窄客户端自由度」的路线，这种取舍直接决定了哪些人用起来顺手、哪些人买完就会后悔。

### 1. 架构与接入优势：免翻墙官网与原生 IP 定位
- **IPLC 专线与 VLESS 协议**：Firefly 标注采用 IPLC 专线接入与 VLESS 传输协议，骨干定位是降低晚高峰跨境丢包率。关于 IPLC 与普通 BGP 中转在跨境出口上的底层区别，可延伸参阅[IEPL 与 BGP 中转架构对比](/comparisons/iepl-vs-bgp-transit/)。
- **免翻墙直达官网**：许多用户最头疼的是主力机场突然失联后，打不开官网面板找新客户端或工单客服。Firefly 明确将「免翻墙访问官网」作为核心特性之一，对于把它当作日常主力或应急工具的用户来说，大幅降低了失联后的找回成本。
- **原生 IP 与多设备政策**：节点重点覆盖香港、新加坡、日本、美国（非晚高峰测速表另含台湾），主打原生 IP 解锁常见海外流媒体与 AI 服务，并标称不限客户端与设备同时在线数量。对于多终端同时在家的个人用户或小家庭而言，无需额外计算设备名额。

### 2. 最大产品限制：2026 年 10 月后无第三方通用订阅
根据正文第 8 条最新说明，Firefly 自 **2026 年 10 月起仅开放官方专属客户端**，用户下载安装包登录后即可一键连接，**不再提供 Clash、Shadowrocket 或 v2rayN 的通用订阅 URL**。

这一变更带来三个非常具体的现实约束：
1. **无法导入通用代理工具**：电脑端的 Clash Verge Rev、FlClash、v2rayN，以及 iOS 端的 Shadowrocket（小火箭）、Stash 均无法接入 Firefly 节点。关于自研 App 与通用订阅在可控性、隐私与多机场容灾上的深层差异，可查看[机场专属客户端与通用订阅对比](/comparisons/custom-app-vs-universal-client/)及[专属客户端潜在风险指南](/resources/proprietary-client-risks/)。
2. **无法融入 Clash 故障转移池**：如果你已经有一家主力包月机场，想买 Firefly 的 **¥100 / 100GB 一次性不限时包**放进 `Fallback` 策略组当自动热备，这个方案是行不通的——断网时你只能手动关闭当前软件，再打开 Firefly 客户端切换，详见[一次性不限时流量包指南](/reviews/onetime-traffic-airports-guide/)。
3. **不支持软路由透明代理**：家里部署了 OpenWrt（OpenClash / PassWall2 / Nikki）做全屋网关的用户，请直接跳过仅有专属客户端的品牌，回到[主流核心机场对比总表](/airport/#core-candidates-table)筛选支持第三方订阅的服务商。

1. **为什么首单最推荐 Firefly Lite 月付，而不是 ¥96 年付版？**

2. **警惕两年付、三年付的历史高额周期诱惑**
   文末 2026-08-09 历史记录中展开了两年付（如 Lite ¥420、Plus ¥756）乃至三年付（Lite ¥540、Nova ¥3119）的阶梯价格，并注明季 9、半 85、年 8 折。无论某个品牌宣称团队成立了多少年，Cross-border proxy 行业本身受国际带宽与监管环境变动影响极大，**切忌在未经自己本地宽带实测前直接购买 2 年或 3 年期套餐**。
3. **支付渠道核实**
   历史存档明确记录 Firefly 的支付方式为 **支付宝 / USDT（无微信）**。虽然随着时间推移官网支付通道可能存在增减，但习惯纯微信零钱付款的用户在注册前请做好需要用到支付宝的准备。

## 四、速率样本解析、AI/流媒体边界与实测缺口

评估 Firefly 的网络质量时，必须严格区分「品牌方提供的非晚高峰样本」和「本站独立测速资料包」。

### 1. 2026-10-19 非晚高峰速率表与美线特征
| 地区节点 | 品牌资料延迟 | 品牌资料下载速率 | 场景可用性评估（非晚高峰基准） |
| :--- | :--- | :--- | :--- |
| **香港** | 27 ms | 547 Mbps | 低延迟高带宽，日常网页、4K 秒开与文件拉取余量充裕 |
| **台湾** | 39 ms | 135 Mbps | 亚太中速梯队，流畅覆盖 1080P/4K 流媒体与常见站 |
| **新加坡** | 42 ms | 445 Mbps | **表现亮眼**，445Mbps 在同类样本中居前，适合 AI 与东南亚业务 |
| **日本** | 57 ms | 147 Mbps | 常规专线均值水平，兼顾日区流媒体与高频查询 |
| **美国** | 143 ms | **30 Mbps** | **相对同类占优**（多数同类美线样本仅 14–20Mbps），可支撑 1080P/4K 缓冲 |

在同批 2026-10-19 品牌资料记录中，光速云、微风、星岛梦、二猫云、SOGO 云的美国样本多落在 **17–19Mbps** 区间，而 Firefly 的美国样本达到 **30Mbps（143ms）**，新加坡也给到了 **445Mbps**。对于需要使用美区原生 IP 访问特定 AI 服务、或连接美国节点观看北美流媒体的用户来说，这是一个值得留意的正面信号。

### 2. 不得忽略的两大验证缺口
- **缺少 2026-08-11 独立测速截图**：在《README_16个机场测速实测资料_最新版》及对应的 `speedtest-manifest.json` 压缩包中，收录了光速云、飞猫云、微风网络、星岛梦、二猫云、唯兔云、U1S1、灵猫网络、一翻云、SOGO 云、全球云、极连云、光年梯、可信云、速界、宇宙云、快狸等实测图，但**并未收录 Firefly 的独立测速截图**。也就是说，上面那张亮眼的速度表目前完全属于 **Vendor Data（品牌方非晚高峰数据）**，尚未经过晚间 20:00–23:00 的跨网实测交叉印证，详情可对照[2026 机场测速横向基准](/comparisons/2026-airport-speedtest-benchmark/)与[节点测速标准与防伪解读](/resources/#intel-transparency)。
- **AI 与流媒体解锁边界**：品牌资料将 ChatGPT、Claude、Netflix、Disney+、YouTube、HBO Max、TikTok、Spotify 标为支持，并将 **Gemini** 明确标注为「视节点而定」。由于没有独立逐节点解锁实测图，如果你核心诉求是稳定调用 Gemini 或特定高风控美区业务，仍需在购买 Lite 月付后自行验证落地 IP 洁净度；若需同时比对更多 AI 工具友好型机场，可参考[AI 工具友好型机场横评](/comparisons/ai-friendly-airports-comparison/)。

## 五、适合与劝退人群决策清单

结合以上核实信息与真实限制，建议在下单前用下方三问快速对号入座：

1. **你是不是只想装一个官方 App、省去找客户端与导入订阅的麻烦，且能接受支付宝或 USDT 付款？**
   - 如果是，且你尤其看重**新加坡 / 美国原生 IP** 与**免翻墙官网入口**，Firefly 适合作为月付试水候选，先用 Lite（¥25 配合 `firefly` 8 折码）跑完一个月晚高峰测试。
2. **你是不是桌面端 Clash Verge Rev、iOS Shadowrocket 或软路由 OpenClash 的固定使用者？**
   - 如果是，**请直接放弃 Firefly**。2026 年 10 月后它已不发放第三方通用订阅，购买后无法接入你现有的分流规则体系，建议转选支持双模式的**光速云（[评测](/reviews/guangsuyun-deep-review/)）**或纯第三方订阅的**微风网络（[评测](/reviews/weifeng-review/)）**、**一翻云（[评测](/reviews/yifan-review/)）**、**唯兔云（[评测](/reviews/weitu-review/)）**。

   - 如果是，Firefly 的常规共享原生 IP 仍属于多人共用池，并不等于「独享静态住宅 IP」，务必阅读[远程办公与独享 IP 边界评测](/reviews/remote-work-vpn-vs-proxy/)及[VPN 与远程办公 IP 选型指南](/vpn/#remote-work-and-ip)。
