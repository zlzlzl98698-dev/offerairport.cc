## 核心结论：先查本地与备用通道，绝不从陌生搜索结果里下载所谓「新版恢复工具」

哪怕是运营了四五年的成熟品牌，在面对突发骨干网络切换、面板前端域名被屏蔽或同业恶意 DDoS 流量攻击时，一年中也总有那么一两次出现官网打开转圈甚至半天连不上节点的慌乱时刻。绝大多数新手在遇到「全线超时 + 官网打不开」的双重打击时，最容易做出两个错误举动：**要么原地急着在搜索引擎乱点排名靠前的假官网李鬼站点（直接被骗走重充钱甚至电脑中毒）；要么慌乱中乱删客户端所有配置文件导致本来还能抢救更新的记录丢失。**

遇到主力服务突然疑似失联，请深呼吸并按下面这套 **4 步标准化应急核查流** 有条不紊地逐级排险，既不虚惊一场误判，也能在真正遭遇跑路时把时间与信息损失降到最低。

识别事前跑路苗头与建置永不失联架构，请协同阅览 [机场跑路预警 6 大前兆清单](/resources/airport-exit-scam-warning-signs/) 与 [主力 + 不限时双活容灾配置指南](/guides/multi-airport-failover-strategy/)。

## 一、快速区分：到底是我电脑挂了，还是服务商真出事了？

在断定人家跑路之前，先用这张简明诊断对照表花 2 分钟缩小范围：

| 故障症状组合 | 最高概率原因 | 第一手正确处理思路 |
| :--- | :--- | :--- |
| **旧节点还能连上外网，但官网域名进不去 / 订阅更新报错** | 当前前端官网域名遭局部 DNS 污染或屏蔽，节点后端正常 | **根本不用慌！** 挂着尚能连接的节点打开官方之前留的永久防失联发布页或更新订阅链接，换到最新镜像域名即可 |
| **官网直连还打得开且能发工单，但所有节点全红超时** | 本地宽带路由器故障、电脑时间偏差超 90 秒、端口被加速器抢占或上游正在临时维护节点 | 先用 [Timeout 九步法排查清单](/clash/fix-node-timeout-errors/) 查本地，并在工单页面看官方公告通知 |
| **电脑连不上，但切到手机 4G/5G 热点瞬间全通** | 当地宽带运营商或小区网关针对特定中转 IP/DNS 做了临时隔离 | 检查路由器重拨换本地公网 IP、调整客户端 DNS 为加密模板，与服务商存亡无关 |
| **官网与备用发布页全挂 + 全部节点全灭超过数日 + 频道失声** | **高危失联（长期遭重创、被清退或实质性跑路）** | 按下文第三部分立即执行改密止损与平滑迁移，**绝对不要再尝试续费赌博** |

## 二、遇到「官网打不开 + 全线超时」时的 4 步标准化应急动作

### 第 1 步：60 秒排除本地环境误伤（千万别漏这一步）

很多看起来「全军覆没」的惨案，最后发现只是 Windows 系统时间慢了两分钟，或者刚装了一款网游加速器接管了网卡：
1. 校准操作系统时钟（在 Windows 右下角「调整日期和时间」点一次 **立即同步**）。
2. 彻底关闭任何游戏加速器、远程会议公司 VPN 或其他同类代理软件后，在客户端右上角只开启基础 `Rule`（规则）模式试一条低延迟冷门备用地区节点。
3. 用手机开启独立移动 5G/4G 个人热点给电脑联机测试（彻底绕过家中光猫与宽带路由），确定是不是家里宽带单方面出了问题。详尽本地排查命令可翻阅 [Clash 全超时排障指南](/clash/fix-node-timeout-errors/)。

### 第 2 步：切入热备通道（或移动临时通道），核验官方真正入口

如果手头早就按我们一贯的容灾建议在 Clash 里放了一家 **「一次性不限时流量包」** 备用订阅（参考 [双机场故障转移指南](/guides/multi-airport-failover-strategy/)），此时只需一键切过去就能立刻重连全球网络！紧接着按以下顺序核实主力情况：
1. 打开注册品牌时邮箱里保存的原始欢迎邮件、或你加入书签的 **「官方永久发布页 / 导航 GitHub / Telegram 官方广播频道」**。
2. 观察官方最近一次更新公告的时间与具体解释：正规品牌遭遇面板迁移或攻击时，通常会在数小时内贴出全新备用官网地址（如更换后缀或更新订阅域名）。

### 第 3 步：按安全前提刷新订阅，切忌开启旧订阅「无脑覆盖盲等」

当确认官方确实只是更换了底层入口地址或发布新订阅入口域名时：
- 如果是 **在原有客户端挂着备用节点的前提下更新主力订阅**：确保在 Clash Verge Rev 该主力配置文件的设置中临时勾选 **「使用系统代理更新 / 走代理拉取（With Proxy）」** 后点击刷新！因为原本旧订阅域名可能在直连状态下已被阻断，必须借备用通道的手去拉新节点列表下来（更新完成后记得看一眼订阅 URL 本身是不是也需登录新官网复制一条全新的）。

### 第 4 步：判定真停摆后的「账号改密与彻底迁出」动作

如果通过外部备用通道查看后发现以下极端局面——**官方备用发布页返回 `NXDOMAIN` 或 `Cloudflare 522` 超时、官方社群连续几周零更新甚至彻底禁言删号、全网节点集体毫无响应持续超 3–7 天**——请立即死心止损，立刻完成以下安全收尾：
1. **立即更换所有复用密码**：如果你当年注册这家机场时用的是同一个常用邮箱和常用习惯密码，火速去把邮箱、GitHub、各大云盘、支付及常用网站里相同密码全部改掉并打开两步验证（2FA）。
2. **清理客户端残留与本地旧代理配置**：从 Clash Verge Rev Profiles 列表里删除这条已死亡的订阅（避免客户端每次打开还在后台偷偷轮询报错域），检查一遍 `C:\Windows\System32\drivers\etc\hosts` 或系统全局代理是否洁净。
3. **只挑选小额月付新方案过渡**：转向新的经过透明度核查的候选服务时，坚决只买 **1 个月最小起步档位**，用晚高峰实测验收完本地流畅度再考虑后续。

## 三、重中之重：失联焦虑期极易踩中的两大「二次收割」钓鱼骗局

每次某家稍微有点名气的老品牌遇到几天短暂波动或失联，搜索引擎与某些劣质导航站就会立刻精准收割走一批惊慌失措的受害者：

1. **假冒官方最新网址 / 冒牌重名站收割重充**：当你在百度搜「XX云 官网打不开」「XX机场 最新地址」时，前几个挂着同样名字、连网站配色和 Logo 都长得一模一样甚至提示「老账号数据库迁移需支付 30 元激活费恢复余额」的页面，**99.9% 是诈骗团伙用同一套开源前端模板连夜搭起来的抢注仿冒站！** 永远只认准你最初在官方渠道亲手存下来的发布页与公告频道，绝对不要通过搜索引擎现找「新域名」。
2. **诱导下载所谓「专属客户端一键恢复连接版」**：任何宣称「老客户端受屏蔽连不上了，快点击此处下载我打包的专用最新版连接器」的非开源 `.exe`/`.apk`，几乎都是趁着停服恐慌期植入的木马包！正经机场恢复线路永远只需要在原有开源客户端（如 Clash Verge Rev、v2rayN、Shadowrocket）里刷新订阅，根本不可能让你临时更换来源不明的私有执行文件（核查客户端安全规则见 [SHA256 文件哈希验证指南](/clash/verify-client-checksum/)）。
