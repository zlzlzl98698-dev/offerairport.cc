## 核心结论：先看 Clash「连接」面板谁在跑流量，再决定是否重置后台订阅 Token

「我明明刚充了一个月 `150GB` 流量包，平时上班摸鱼查查资料、晚上也就看了两小时视频，怎么第四天登录机场面板一看，流量居然只剩 12GB 了？难道这家机场后台在偷偷作弊扣量？」

几乎每个长期使用代理工具的人都经历过这种血压飙升的瞬间。但在急着找客服吵架或换机场之前，**先把 Clash Verge Rev 左侧那个宝藏监测界面点开查 30 秒——超过 90% 的流量异常暴涨，元凶其实就安静地运行在你自己电脑后台，或是你的订阅钥匙已经不知不觉被人蹭上了！**

按下面这套 **「本地抓真凶 → 算清倍率账 → 切断公网蹭网 → 一键重置订阅密钥」** 的 4 步止损流，几分钟内即可锁定漏点并彻底堵死失血口。

有关如何从规则底层永久放行下载器进程，以及避免被第三方在线转换泄漏订阅，请配合参阅 [Clash 规则与进程直连配置](/clash/verge-rules-and-proxy-groups/) 与 [订阅格式安全转换指南](/clash/subscription-format-conversion/)。

## 一、快速锁定本地「偷流量真凶」的 5 大高频原因

| 常见偷跑元凶 | 典型触发场景 | 为何能迅速榨干百 GB 流量 | 直观排查与止损定位 |
| :--- | :--- | :--- | :--- |
| **1. 下载器 / 网盘 / 游戏平台更新器未直连** | 开着全局模式或 TUN 模式挂载迅雷、qBittorrent、百度网盘、Steam 下载大型客户端 | 单部 4K 资源或大型游戏更新动辄 40–80GB，全绕着国外中转绕圈走完 | Clash **「连接（Connections）」** 面板瞬间看到 `Thunder.exe` 等进程排名高居第一；立刻用 `PROCESS-NAME` 设直连（详见 [审计与直连避让](/resources/airport-audit-rules-explained/)） |
| **2. 云盘后台静默备份 / 系统升级补丁** | 开启 TUN 模式期间，iCloud 照片库同步、OneDrive 自动上传或 Windows Update 拉镜像 | 这类海外云同步服务域全都在 `PROXY` 代理列表内，后台静悄悄双向收发几十 GB | 在「连接」栏搜 `apple`、`icloud`、`microsoft`、`onedrive`；暂停大型同步或改开非全机接管的系统代理模式 |
| **3. 误用高倍率（`2x / 3x / 5x`）稀缺专线节点** | 只看延迟绿选了一个带有 `x2` 或 `x3` 标签的高级落地节点并整晚看 4K 视频 | 实际下载 20GB 4K 视频流，后台直接按 `20 × 3 = 60GB` 乘数暴扣额度 | 回到节点清单核实名称后缀倍率，日常看大图/视频务必选 **`1x`（1 倍率）** 主流节点（详见 [计费规则 FAQ](/resources/airport-billing-faq/)） |
| **4. 公共 Wi-Fi 环境下开着「Allow LAN」无密码裸奔** | 之前为了给 Switch / 手机共享网络在学校或公司、咖啡馆开了「允许局域网连接」忘记关 | 同局域网内的扫描器或其他人直接连接你的电脑 IP `7897` 端口白嫖海外高清流量 | **不用时立刻在主页面板关闭 `Allow LAN` 开关**，或设置严格验证密码并只在信任家庭内网开放 |
| **5. 客户端「自动测速心跳」设得太激进** | 自己乱写配置文件把 `url-test` / `fallback` 的健康检查 `interval` 设成了 10 秒一轮且挂着几百个节点 | 每隔几秒并发几十上百次 TLS 握手测验，积少成多每天暗自消耗掉一大截 | 将自动健康检查间隔调整至 `300–600` 秒以上，或关闭无用冗余订阅集合的高频自动探测 |

## 二、30 秒现场抓包：用 Clash Verge Rev「连接」页面抓出流氓消耗

不要凭感觉猜是谁吃了流量，按照这两步让真实进程原形毕露：

1. 打开 **Clash Verge Rev** → 点击左侧菜单栏中的 **「连接（Connections）」**（图标通常为上下箭头或网络节点）。
2. 查看界面上方及表格列，找到 **`上传 (Upload)`** 与 **`下载 (Download)`** 实时速率，或者直接点击列表右上角切换排序规则为 **「下载总流量降序 / 上传总流量降序」**（部分版本可直接看顶部「总计流量」走势与活跃连接大户）。
3. **抓现行识别技巧**：
   - 你会清晰地看见每一条活跃连接的 **`进程名 (Process)`**（仅在开启 TUN 或本机环回捕获时清晰可见，例如 `chrome.exe`、`qbittorrent.exe`、`svchost.exe`）、**`目标域名/IP (Host)`**、**`命中规则 (Rule)`** 与 **`所走节点 (Chains)`**。
   - 一旦发现某个你根本没主动在看的软件（比如后台某国产播放器内置的 PCDN 上传服务，或 `svchost` 系统推送服务）正在跑着几十 MB/s 的流量走着你的海外主策略组，立刻点击旁边的小叉切断连接，接着按 [进程前置直连教程](/resources/airport-audit-rules-explained/) 把它拉进 `DIRECT` 名单！

## 三、怀疑被别人拿走了订阅链接？两分钟完成 Token 重置与全端封堵

如果你仔细排查过本机「连接」清单、发现自己关了所有电脑睡觉的一整夜里，机场后台账面剩余流量还是凭空少了十几 GB——并且**后台面板的「当前在线 IP 数量」或「设备访问记录」出现了陌生省市记录**——那基本可以确认为 **「订阅链接（Token）已外泄」**。

最常见外泄途径包括：**截图发群聊没打码暴露了完整 URL、电脑曾经误装过山寨捆绑端、或者把订阅地址粘进过不明网页版免费在线订阅转换器！** 请立即执行以下抢救步：

1. **登录服务商官网控制面板**（使用你最开始保存的正规书签地址）。
2. 在仪表盘主页、账号设置或「我的订阅」旁边，找到并点击 **「重置订阅信息 / 重置订阅链接 (Reset Subscription URL / Token)」** 并确认操作。
3. **立刻触发的效果**：你原来那条带有旧 `?token=xxxx` 的 URL 瞬间永久作废，不管是偷用你链接的陌生人还是泄露出去的旧软件，在下次试图连接或更新配置时都会全部失效甚至当场断联（部分系统需同时手动点一次「重置连接密码/UUID」确保正在挂着的长连接也被踢下线）。
4. **重新导入与清理安全环境**：
   - 将新生成的干净订阅链接重新导入你**本人亲自验证安全**的桌面 Clash Verge Rev 与手机端；
   - 如果此前在某可疑网站改过登录密码或同款密码也用在其他网站，顺带修改面板登录密码并停用所有来历不明的在线订阅转换站（如需做聚合过滤，请参考使用本地运行的 [Sub-Store 部署方案](/clash/sub-store-local-deployment/)）。

掌握这一整套「本地排查流量黑洞 + 后台快速一键止损重置」流程后，任何流量账目异常问题都能在 5 分钟内定位水落石出，再也不会莫名其妙背黑锅白丢钱。
