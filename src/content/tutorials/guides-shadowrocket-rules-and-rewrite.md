## 核心结论：用小火箭原生规则匹配 + 策略组，无需反复手动开关切节点

在 iOS 端所有付费代理软件中，**Shadowrocket（俗称「小火箭」）** 凭借极高的稳定性、轻巧的内存占用和广泛流传的配置规则格式成为多年装机首选。但大量 iPhone 用户装好小火箭后只停留在「首页点连香港看视频 → 打开 ChatGPT 报错地区不支持 → 手动切去美国节点 → 刷 YouTube 卡顿又切回香港」的反复折腾中，甚至误把顶部「全局路由」设成 `代理` 导致微信和国内 App 一起跟着绕远路费流量。

其实只需要花 5 分钟理解 **「全局路由：配置模式」「独立域名策略组」「按需连接与 UDP 调优」** 这三处关键设置，你的 iPhone 就能像桌面端的 Clash Verge Rev 一样做到「国内 App 毫秒直连、流媒体默认高速港台、AI 提问自动无感走美日」——全天不用再手动切一次节点。

尚未购置和下载安装外区工具的用户，请先查阅 [iPhone / iPad 客户端下载避坑指南](/guides/ios-proxy-clients-guide/)；若你想在苹果设备上原汁原味复用电脑 Clash Verge Rev 的 YAML 逻辑，可对照阅读 [Stash iOS 覆写迁移教程](/guides/stash-ios-clash-override/) 与 [iOS 代理软件横评](/reviews/ios-proxy-apps-review/)。

## 一、先打好底座：分清「首页全局路由」四种开关状态

打开 Shadowrocket 首页，在节点列表上方有一个很容易被忽略、但决定了全机流向的核心选项卡——**全局路由（Global Routing）**。它的四个选项含义完全不同：

| 全局路由模式 | 实际流量走向行为 | 适用情景 | 常见误区警告 |
| :--- | :--- | :--- | :--- |
| **配置（Config）** | 严格按照底栏「配置」中生效的 `.conf` 规则文件执行：国内直连、海外代理、广告拦截、特定域名走特定节点 | **99% 日常主力默认首选状态** | 新装完软件后往往默认在配置模式，但若没选中完整规则或规则为空则只剩直连 |
| **代理（Proxy）** | 不看规则，除极少数本地内网外，**全部流量强制转发去你选中的那个节点** | 仅用于排查某个冷门海外域名到底是不是没被分流规则收录 | 长期保持此模式会导致微信、抖音、百度网盘耗费海外付费流量且极卡 |
| **直连（Direct）** | 保留手机顶部 VPN 连接图标，但所有请求都不经过海外代理直接本地发出 | 临时配合特殊抓包调试或仅用本地 DNS / 模块功能而不翻墙 | 选了这个还纳闷为什么节点明明连上了却打不开谷歌 |
| **场景（Scene）** | 根据当前连入不同的 Wi-Fi 名称（如公司内网 vs 家庭宽带）自动套用不同的路由配置 | 经常往返特定 Wi-Fi 需要自动切换直连或特定配置的高阶场景 | 不熟悉的普通用户维持在「配置」即可 |

## 二、实战教程：5 分钟给 ChatGPT / Claude 配好独立分流规则

很多朋友平时看香港、台湾高带宽低延迟视频体验拉满，唯独用 OpenAI ChatGPT 或 Anthropic Claude 时提示香港 IP 不受支持。下面直接在 Shadowrocket 里给它们「开一条专用高速分流通道」：

### 步骤 1：在底栏「配置」选择一份标准分流基础模板

1. 点击底部导航 **「配置」**。
2. 如果你此前导入的默认配置文件规则太老或者干脆没有任何规则，建议在页面内保留默认基础配置或点击从可信源恢复一份干净的带国内外分流与规则占位的基础 `.conf`（注意不要随意导入陌生网友分享的、来历不明且带有大量隐藏复杂 HTTPS 重写/MITM 证书的魔改文件，谨防数据劫持！）。
3. 点击当前正在生效（左边带橙色标记）的配置文件右侧的 **`i` 信息图标** → **「编辑配置」** 或直接点开该配置名称进入规则查看。

### 步骤 2：建立「AI 独立出站规则」指向具体美/日/新节点

1. 进入该配置详情页的 **「规则（Rules）」** 列表。
2. 点击右上角的 **`+`** 号添加新规则：
   - **类型（Type）**：选择 **`DOMAIN-SUFFIX`**（域名后缀匹配，最省事且覆盖所有子域名）。
   - **策略（Policy）**：不要选总默认的 `PROXY`，直接下拉挑选你订阅列表中一条明确标注支持 AI、且延迟较低的**美国、日本或新加坡节点**（如果你的配置文件自带名为 `AI` 或 `OpenAI` 的策略组，直接指向该策略组更佳！）。
   - **值（Domain）**：依次添加下面几条最核心的 AI 服务主域（每次加一条点保存，或者使用 `DOMAIN-KEYWORD` 如 `openai` 辅助覆盖，但精确 `DOMAIN-SUFFIX` 误伤率最低）：
     - `openai.com`
     - `chatgpt.com`
     - `oaistatic.com`
     - `oaiusercontent.com`
     - `anthropic.com`
     - `claude.ai`
     - `gemini.google.com`（若使用 Google Gemini 需要一并锁定非香港支持地区）
3. **检查规则排序优先级（极关键！）**：新加的独立规则必须排在末尾默认兜底规则 `FINAL` 以及大范围通用 `GEOSITE/PROXY` 规则**之前**。因为 Shadowrocket 匹配规则是从上往下「首条命中即止」的，如果这几条掉在了 `FINAL` 下面，就永远不会触发！

### 步骤 3：保存并实测验证是否成功分流

回到首页确保「全局路由」停在 **`配置`**，把主列表中的默认选中节点停在顺滑的 **香港高速节点** 上并打开开关。此时用手机 Safari 打开测 IP 工具观察主出口应为香港 IP；随后紧接着打开 ChatGPT App 发起对话或登录，此时观察首页右侧/顶部的状态指示或「连接日志」，你会发现 `chatgpt.com` 已经自动绕道日本/美国节点完成请求并顺利回复！

## 三、小火箭进阶模块、测速模式与 iOS 省电长连调优

1. **把默认 Ping 改成「连通性」测速，别再被假绿色数字骗了**：
   - 进入底部 **「设置 → 测速方法」**，默认可能是 `TCP`（只测到国内入口中转机房的握手毫秒数）。
   - 改为 **`CONNECT` 或 `URL` 真实连通性测试**，这样在首页点击「连通性测试」时，返回数值代表流量切实通过该节点打通了外网测试页，能够一秒剔除只剩中转空壳的失效节点。
2. **开启「按需连接（Connect On Demand）」防切换 Wi-Fi 掉线**：
   - iPhone 用户经常觉得「进电梯没信号再出来，或者回家连上 Wi-Fi，小火箭明明开关开着却突然全网没网」。
   - 打开 **「设置 → 按需连接」**，打开主开关并勾选按需规则；此外建议检查 **「设置 → UDP」**，确保打开 **`转发`（UDP Forwarding）** 开关，否则 WhatsApp 语音通话、Telegram 语音、部分实时推流与 Hysteria2 节点将无法正常工作。
3. **谨慎启用「HTTPS 解密（MITM）」与来路不明模块（Modules）**：
   - 小火箭支持非常强大的「脚本（Script）」与「模块（Module）」去广告或网页重定，但任何开启了 `HTTPS 解密` 并安装根证书（CA Certificate）的操作，理论上都赋予了对应外部脚本读取并篡改解密 HTTPS 明文包的能力。
   - **安全准则**：普通用户仅仅为了正常科学上网与 AI/流媒体分流，**完全不需要安装任何要求信任 MITM 根证书的第三方神秘脚本**；保持纯规则分流不仅零隐私风险，而且 iPhone 电池续航能显著更耐用。
4. **启用「分片/兼容设置」应对特殊校园/移动网络**：
   - 如果在特定酒店 Wi-Fi 或移动 5G 下频繁断流但桌面版用着很稳，先检查底栏 **「配置」** 里是不是被关闭了本地 `DNS` 防污染或者 `prefer-ipv6` 引起异常，通常保持开启客户端内置 **`UDP` + `IPv6 关闭或自动回退`** 即可改善绝大多数双栈转圈故障（双栈冲突原理见 [IPv6 冲突与双栈修复教程](/resources/ipv6-conflict-and-dual-stack-fix/)）。
