## 核心结论：「传输协议」决定加密与伪装方式，「底层线路」决定物理拥堵与稳定性

很多刚入门翻墙工具选型的朋友，在看各家服务商介绍和测速评测时，最容易陷入一个认知陷阱：把 **「协议（Shadowsocks / VMess / Trojan / VLESS-Reality / Hysteria2）」** 和 **「底层线路（海外直连 / BGP 公网中转 / IEPL & IPLC 物理专线）」** 混为一谈。甚至有人专门满世界找写着 VLESS 的便宜节点，以为换个新名词协议就能在晚高峰跑满千兆宽带。

用最通俗的物流系统来打个比方：
- **代理传输协议（Protocol）**：相当于你寄国际快递时，包裹里面怎么装箱封口、外面贴不贴伪装面单、防不防安检X光机拆箱窥探（解决的是**隐私安全性、抗探测阻断能力、手机和路由器的计算性能耗电**）。
- **底层传输线路（Routing / Line）**：相当于包裹发出去之后，到底是走乡间坑洼土路挤进拥堵港口（公网普通直连），还是直接坐上点对点直达的高铁货运专列（IEPL/IPLC 物理内网专线）——**它才直接决定了你的 21:00 晚高峰丢包率高不高、油管 4K 卡不卡、延迟跳不跳水。**

进一步深入两种技术路径对比，可以同步阅读 [VLESS-Reality vs Trojan vs Hysteria2 横评](/comparisons/vless-trojan-hysteria2-comparison/) 与 [IEPL 专线 vs BGP 公网中转对比](/comparisons/iepl-vs-bgp-transit/)。

## 一、五大主流代理传输协议横向拆解（2026 实用视角）

| 协议名称 | 底层传输载体与特征 | 核心技术优势 | 明显短板与使用条件 | 最常见的合法合理落地姿态 |
| :--- | :--- | :--- | :--- | :--- |
| **Shadowsocks (SS / SS-2022)** | 轻量对称流加密 / AEAD（TCP/UDP） | **客户端极省电、性能开销最低**、兼容最老旧的小内存硬路由 | 若直接用于**公网跨海直连极易被识别阻断** | 配合 **IEPL/IPLC 物理专线或国内加密中转入口** 做高速轻负载转发 |
| **Trojan** | 伪装成标准 HTTPS (TLS 1.3) 加密流量 | 行为特征高度贴近正常网页访问、兼容几乎全部新老通用客户端 | 建立握手需要标准域名证书；比裸 VLESS 略多一点点包头 | 综合型专线与 BGP 中转主力机场（如唯兔云、部分老牌站点常用） |
| **VLESS (XTLS-Vision / Reality)** | 无多余自建加密层的极简传输框架；Reality 可借用真实大站 TLS 指纹伪装 | **抗主动探测封锁最强**、避免「TLS 套 TLS」双重计算冗余、支持原生高效转发 | 老旧且早已停更的传统客户端（如原版 CFW）不支持 Reality | 无论中转专线还是高质量单线自建，当前绝对主流现代协议（如一翻云、光速云标称等） |
| **VMess** | 早期 V2Ray 核心带内部加密的经典协议 | 历史上曾统治生态多年、支持多种传输包装 | 算法相对沉重耗费算力、**要求电脑与服务器时间差不能超 90 秒** | 老版本存量服务兼容；新架构基本已被更干净的 VLESS 取代 |
| **Hysteria 2** | 基于 **UDP / QUIC** 并引入定制拥塞控制算法 | **弱网高丢包克星**！跨洋直连或高丢包公网环境下仍能暴力拉起大带宽 | **依赖 UDP**：校园网、公司企业防火墙与部分移动基站易限速阻断 UDP | 校园网特殊调优、廉价公网直连大带宽或补充备用链路 |

> **一句话纠正偏见**：看上面那张表你就明白，**遇到写着 Shadowsocks 协议的节点先别着急嫌弃它过时**——先看它入口 IP 是不是国内广深/沪京 BGP 专线中转 IP，只要隧道前端在国内且后台明确说明走 IEPL 内网出境，SS 反而是让软路由跑满千兆且 CPU 占用低到忽略不计的最优解之一；反过来，如果一条标注 VLESS-Reality 的线路卖几块钱但入口直接指到海外美国小机房，晚高峰公网国际出口一堵一样动弹不得。

## 二、三大底层传输线路：为什么价格差出好几倍？

既然协议决定不了网速上限，真正拉开服务商硬件采购成本与晚高峰实际体验差距的，就是底层走的三条路：

### 1. 海外直连（Direct Connection）
- **工作原理**：你的手机电脑本地宽带发出加密数据包后，直接经由中国电信（163骨干）、中国联通（4837）、中国移动（CMI）的普通民用国际出口，一路经过十几个公网路由跳点抵达海外普通 VPS 机房。
- **体验特征**：凌晨三点钟不拥挤时跑得飞快，但一到晚上 `20:00–23:00` 高峰期，所有普通民用宽带挤在同一条公网海底出口上，丢包率轻易飙升至 10%–30%，网页转半天或视频画质自动掉回 360P。除非购买昂贵的电信 CN2 GIA / 联通 9929 等商业级公网优化线路，或者叠加强效抗丢包协议如 Hysteria2 抢带宽，否则很难承载稳定办公重任。

### 2. 公网 BGP 多线中转（BGP Transit）
- **工作原理**：你在国内先高速直连一台位于**国内优质 BGP 多线机房**（例如深圳、广州、上海、杭州的阿里云/腾讯云或独立多线中心）的「中转入口机器」，通过它再转发到海外落地服务器。
- **体验特征**：有效治好了各地铁通、广电、校园网与单一运营商跨网延迟奇高的老毛病，进入国内中转入口的这段极快（往往仅 10–35ms）；但从国内机房发往香港或日本的出海那一段依然走行于公共互联网国际出口，遇到特定周期大流量波动或特殊防护期仍可能出现短时波动或拔线维护。

### 3. IEPL / IPLC 跨境物理内网专线（Private Line）
- **工作原理**：服务商向电信级基础运营商重金采购点对点的**企业级内网物理专线**（常见如深港 IEPL、沪日 IPLC、京日专线等）。流量从国内核心节点进入专属内网通道直接传输到香港/日本落地网关，**完全物理绕开拥挤的公共互联网国际出口**。
- **体验特征**：
  - **晚高峰极稳**：不管外部民用公网拥堵成什么样，物理专线受公网波动与国际出口 QoS 限流的影响微乎其微，延迟波动极其收敛（玩实时音视频会议、远程桌面 SSH、高频同步代码最明显）。
  - **硬件带宽极为昂贵**：每 Mbps 物理专线采购价远非公网机器可比，因此真正全段采用真 IEPL/IPLC 专线的正规服务，月付合理成本往往在 **¥18–¥35 起跳**（对应年付轻量档也在 ¥79–¥99+ 区间），很难出现“¥3 一个月 1000GB 不限速真专线”的违背物理成本神话。想对照各品牌真实专线标注与截图核验，可直接看 [机场品牌数据透明与对比](/airport/#core-candidates-table) 及 [光速云/唯兔云/一翻云等品牌核验库](/brands/)。

## 三、普通用户根据场景直接抄作业的「协议 + 线路」搭配公式

1. **追求绝对稳、主力远程工作 / AI 编码 / 视频会议**：选明确采用 **IEPL/IPLC 专线（或高质量 BGP+专线混合）+ Trojan / VLESS / SS** 组合的服务，搭配支持 Mihomo 内核的 [Clash Verge Rev](/clash/verge-complete-guide/)，开启稳定分流规则即可。
2. **大学宿舍校园网 / 出差酒店网络 / 移动大内网经常连不上**：这类网络对 TCP 常有奇葩限制或反过来彻底封死 UDP，建议订阅里**同时兼备 VLESS-Reality（走 TCP/TLS 端口伪装）与 Hysteria2（QUIC 抢占加速）双协议并存**的节点池，连不上立刻换另一种底层传输，Hysteria2 针对校园网的专门调优可看 [Hysteria2 校园与弱网调优指南](/resources/hysteria2-campus-network-tuning/)。
3. **跨全端多设备、既接机场又连自建 VPS 测试机**：底层同时需要拉起 Xray、sing-box 与 Mihomo 核心能力，首选 [v2rayN](/clash/v2rayn-multi-core-guide/) 或详阅 [Mihomo 内核核心能力与多协议支持解析](/clash/mihomo-core-features-guide/) 与 [sing-box vs Mihomo 内核取舍](/comparisons/sing-box-vs-mihomo-core/)。
