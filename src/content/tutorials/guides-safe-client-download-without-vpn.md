## 核心结论：渠道可以借用临时通道或朋友传包，但「SHA256 哈希核验」一步不能省

当你刚买了一台全新笔记本、重装了 Windows/macOS 系统，或者刚刚在公司拿了一台净机——此时电脑里**没有任何代理客户端**，打开浏览器想去 GitHub 官方页面下载正版开源 **Clash Verge Rev** 或 **v2rayN**，结果网页转半天提示连接被重置，好不容易刷出 Releases 列表，点一下 40MB 的安装包却以每秒 `8 KB` 的龟速下载并在第 2 分钟彻底中断。

这就是几乎所有人在冷启动阶段都会遇见的 **「鸡生蛋死循环」**：要上 GitHub 下翻墙软件，得先有翻墙软件才能顺畅上 GitHub。而中文互联网大量木马黑产正是看准了新手在这个瞬间急躁、不想折腾的心理，在各大搜索引擎竞价投放高仿「中文官网」「绿色高速直装版」守株待兔。

下面教你用**零风险的冷启动闭环流程**渡过第一次配置期——核心思路一句话：**下载通道可以灵活变通，但文件落盘后的官方哈希校验（SHA256）绝不妥协。**

配合具体软件官方源仓库辨别与命令行核对命令，请同步参阅 [Clash Verge Rev 官方安全下载指引](/clash/verge-official-download-guide/) 与 [SHA256 文件哈希核验实操指南](/clash/verify-client-checksum/)。

## 一、安全度过「冷启动」的 4 种正确姿势

| 冷启动通道方式 | 可用场景说明 | 操作安全度 | 实施要点与前提条件 |
| :--- | :--- | :--- | :--- |
| **1. 用已通网的手机 / 备用设备从官方下载再传电脑** | 绝大多数场景（最推荐！） | **极高** | 手机已有代理直接访问 GitHub Releases 拉官方 `.exe`/`.dmg`，再 AirDrop/数据线/微信文件助手传回电脑做哈希对比 |
| **2. 切换移动端热点或清晨非高峰直连尝试** | 某些宽带 DNS 污染但移动 4G/5G 偶可直通 | **极高** | 电脑临时连手机个人热点访问真实 `github.com` 仓库拉取，部分轻量客户端包仅 20–40MB 往往一次就能拉完 |
| **3. 向身旁可信同事/技术朋友拷贝离线包并核验** | 办公内网严密或手机也没任何工具时 | **高（强制补验哈希）** | 只管收下安装包文件，自己跑 `Get-FileHash` 并对照真实官方 Release 页面校验码 |
| **4. 使用极少数已知合规软件本身的「官网下载页+官方镜像」** | 仅限于完全不走 GitHub 且服务商正规自研 App | 视品牌透明度而定 | 仅可从你在可信途径核实过的官方主站域获取，且必须核实并非搜出来的广告钓鱼站 |

### 实操步骤拆解（以「手机协助下载 + 电脑终端核验」为例）

1. **在已配置好代理的手机（或备用平板）上**：打开浏览器访问正确的开源项目 GitHub 官方仓库主页（如核实好拼写无误的 `clash-verge-rev/clash-verge-rev` 或 `2dust/v2rayN`，避免在搜索引擎随便点广告链接）。
2. **下载安装包并顺手截图/复制 `sha256` 原文**：在 `Assets` 列表里下好对应新电脑架构的文件（比如 Win11 下 `x64-setup.exe`，M 系列芯片 Mac 下 `aarch64.dmg`），同时把官方发布的 `sha256sums.txt` 或正文校验值文本一起保存或截图。
3. **物理或局域网传送到新电脑桌面**（通过数据线连接、苹果 AirDrop 或常用文件传输通道发送原文件，注意不要经过某些会自动压缩重打包的途径，或者选择「原文件」发送）。
4. **在电脑上运行 10 秒哈希对比（绝不可省）**：
   - **Windows 电脑**：桌面打开 PowerShell 运行 `Get-FileHash .\你的安装包名.exe -Algorithm SHA256`。
   - **Mac 电脑**：终端运行 `shasum -a 256 ~/Downloads/你的安装包名.dmg`。
   - 把终端算出来的 64 位字符串，逐字比对你手机上 GitHub 官方网页截图里的数字（哪怕只比前 8 位 + 中间 4 位 + 末 8 位也能瞬间识别改动，最好全串 `CTRL+F` 或相等判断对比）。**只有完全一致，才允许双击安装！**

## 二、绝对禁止触碰的 4 条冷启动红线

在还没有拿到可信工具之前，下面这些「看似最快」的捷径实际上是电脑被植入剪贴板木马、后门远控的最主要原因：

1. **严禁通过百度/必应/360 搜索「Clash 下载」「Clash for Windows 官网」「v2rayN 官网」直接点排在前排的站点下载**：开源客户端团队几乎没有建所谓面向国内优化的 `.cn` / `.cc` / `.xyz` 中文一键直下载站，你在中文网页上看到的精致蓝白色「Clash 官方下载页」99% 以上属于欺诈投毒网站，专门修改二进制拦截你的加密货币地址或账户凭证。
2. **严禁运行任何「绿色一键集成免费节点版」压缩包**：所有正规开源客户端都不带任何免费节点；任何一装好自带节点能跑、甚至要你关闭 Windows Defender 的打包文件，属于高危木马。
3. **严禁在同一个非官方下载站里抄取所谓「官方 MD5/SHA256 校验值」**：逻辑很简单——黑客既然自己动手重打包了木马包，自然顺手会拿这只木马包算出新的假哈希贴在自己的钓鱼网页旁边！哈希参考标准必须由你通过真实 `github.com` 域名亲自查看核对，绝对不能由同一个下载网页既当裁判员又当运动员。
4. **切忌从网盘（百度盘/夸克网盘）陌生分享链接里直接盲信运行程序**：哪怕标题写着「亲测可用无毒纯净版」，除非你自己拿原发布仓库公布的官方 SHA256 亲自验证它是一比特不差的原始搬运件，否则一律不运行。

## 三、拿到正版安装包后下一步怎么立刻跑起来？

成功用安全路径装好正版软件只是拿到了干净的「播放器」，接下来按顺序完成这两步即可正式打通网络：

1. **导入合法订阅并验证**：打开 [Clash Verge Rev 订阅导入及报错排查](/clash/verge-subscription-import-guide/)，贴入你选好并完成支付测试的机场订阅链接，将模式切到 **`Rule`（规则模式）**。
2. **Mac 与 Linux 权限收尾**：如果你用的 Mac 因为软件未付苹果公证费弹窗报「已损坏，无法打开」，在**已通过 SHA256 核验安全**的前提下，再去参照 [macOS Gatekeeper 解除隔离指令指南](/guides/macos-proxy-clients-guide/) 放行；Windows 如遇 UWP 商店和终端不通，直接按指南安装 Service Mode 开启 TUN（[Windows UWP 与 WSL2 指南](/clash/windows-firewall-and-uwp-loopback/)）。

更多客户端真伪辨别及防骗方法论，可回到 [Clash 官方下载与客户端矩阵](/clash/#official-download) 或查看 [免费梯子隐私与投毒风险审计](/guides/free-proxy-security-risks/)。
