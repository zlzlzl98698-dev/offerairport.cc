## 核心结论：看懂四组核心词汇（线路、计费、IP 质量、客户端状态），就看懂了 95% 的评测与套餐说明

刚踏入跨境代理世界，打开各种评测文章或者服务商后台面板，映入眼帘的全是令人头大的缩写与黑话——什么「深港 IEPL 1x 倍率」「三网 BGP 入口」「广播 IP 无法解锁」「ChatGPT 降智」「0.2x 下载专用」「在线设备审计」「YouTube 送中」。

很多用户正是因为没弄明白这些词汇背后的真实技术约束，不是花冤枉钱买了根本不适合自己宽带的线路，就是在 `3x` 节点上不知不觉把一个月的流量一天耗光。下面按 **网络线路与架构、计费与资源约束、IP 纯净度与流媒体、服务端风控与排障** 四大分类，逐条给出准确、通俗且没有水分的百科解释。

## 一、线路与网络架构类核心词汇

| 常见术语 | 完整技术含义 | 对普通用户真实影响 | 选型观察重点 |
| :--- | :--- | :--- | :--- |
| **入口（Ingress / Entry）** | 你本地电脑/手机第一跳连接上的服务器位置（多在国内广深/沪/京等地） | **决定你的物理延迟下限**以及跨网丢包与否 | 南方优选广深入口，北方优选京沪；支持 BGP 多线更防电信/联通/移动互通降速 |
| **落地（Egress / Exit）** | 流量最终在海外冒头访问 Google/Netflix 的出口服务器 | **决定你的 IP 归属国、流媒体和 AI 工具能否解锁** | 光有好入口不够，落地 IP 脏或被官方拉黑同样弹验证码甚至拒接 |
| **IEPL / IPLC 专线** | 国际以太网专线 / 国际专线出租电路（跨边界物理内网通道） | **不经过公网拥堵国际出口**，晚高峰几乎不受波动与丢包干扰 | 硬件带宽采购价极高，因此全专线品牌很难出现几块钱超大流量真包月 |
| **BGP 中转** | 入口采用同时接入三大运营商的多线机房，再转出至海外服务器 | 国内接入顺滑不挑宽带运营商，性价比高 | 跨境那段仍走公网优化出口，大波动期间稳定性略逊物理内网专线 |
| **海外直连（Direct）** | 没有任何国内中转跳板，本地宽带直接跨海连海外普通机器 | 成本极低，但晚高峰公网丢包严重，延迟跳变大 | 除非是 CN2 GIA 等贵价优化或搭配 Hysteria2 抢网速，不建议作主力 |
| **冷门国家 / 小众地区节点** | 例如新加坡之外的阿根廷、土耳其、印度、南非、尼日利亚等落地 | 常用来注册或低价区数字会员、或测试特定地区限定内容 | 注意小众地区经常由**普通机房中转跨大洲跳转**且可能伴随高倍率扣流 |

## 二、套餐与流量计费类术语（防止花冤枉钱）

- **流量倍率（Multiplier，常见 `0.2x`、`0.5x`、`1x`、`2x`、`3x`）**：节点名字后面或说明里带的数字乘数。代表你实际下载 `1GB` 文件时，账号总剩余额度会被扣除多少 `GB`。例如在站内多款核查品牌（如光速云常规标记、唯兔云全节点 1 倍、星岛梦常规 1 倍标注）中均以 `1x` 为常见基础；如果某冷门稀有住宅节点或超贵专线标了 `2x`，下载 `10GB` 电影系统会给你扣掉 `20GB`。而标注 `0.2x` 或 `0.5x` 的节点常用于跑大体积系统更新或挂后台下资料以节省账面配额。
- **重置日（Reset Date）**：每个周期恢复满额可用流量的那一天。常见为按购买当天的日期每 30 天重置，或者全站统一在每月 1 号重置。注意：**常规按月/年重置包月底用不完不会结转累加到下个月**，只有单独购买的「一次性不限时按量包」才永久保留直到用完为止。
- **不限设备数 vs 并发 IP 限制**：后台标注「不限设备数」，本质含义是「不卡死你个人手机、电脑、iPad 上导入几个客户端」。但绝大多数商家在服务条款里都暗含一条红线：**禁止把个人订阅链接发布给陌生人或淘宝合租分账**，一旦后台检测到短时间内出现大量跨越不同城市/不同运营商的同时在线连接 IP（高并发异常），轻则限速踢出，重则直接永久封禁账号。
- **单节点限速 / 峰值带宽（如 `2.5Gbps`、`不限速`）**：指的是服务端入口/落地单点网卡能力或软件限速策略上限（例如有的入门超低价套餐会限制单个用户最高只能跑到 `50Mbps–100Mbps`，而如部分品牌标称不限速或 2.5Gbps 端口）。但实际在你家的电脑里最终能跑出多快，还取决于你家宽带自己的签约上限、当地晚高峰拥堵情况以及本机路由器转发性能。

## 三、IP 纯净度、解锁能力与流媒体常用术语

- **原生 IP（Native IP） vs 广播 IP（Anycast / Announced IP）**：
  - **原生 IP**：IP 地址在互联网数字分配机构（ARIN/APNIC/RIPE 等）里登记的所属国家，与目前这台物理机所在机房的国家**完全一致**，而且归属信誉良好。往往对当地严格版权流媒体（如日本动画平台、区域限制电视直播）支持度极好。
  - **广播 IP**：服务商把注册在甲国（比如美国或欧洲）的一段 IP 广播路由挂到了香港或日本的机器上使用。平时查延迟只有几十毫秒、打开普通网页也完全正常，但在个别版权极其敏感的流媒体平台眼里，有时会被当成美国归属或代理中转 IP 识别拦下。
- **机房 IP（Datacenter IP） vs 家宽 / 住宅 IP（Residential IP）**：普通机场绝大多数使用数据中心机房大带宽服务器（Datacenter IP）；真正从海外普通民用运营商拉出来的家庭宽带（ISP/住宅 IP）带宽极昂贵且极其稀缺，主要用在极其严苛的跨境店铺收款与高敏账号养号，并非日常看视频刷网页的必需品（详情及检测办法见 [IP 纯净度与 AI/流媒体自检实战](/resources/ip-purity-and-unlock-check/)）。
- **流媒体解锁（Netflix / Disney+ / TikTok 解锁）与 DNS 解锁**：指使用该节点能否看到 Netflix 非自制版权剧集或正常打开对应地区服务。现在很多机场并非全节点购买昂贵本土原生 IP，而是在落地端通过后端 **DNS 解锁中继技术**，把针对 Netflix 或 ChatGPT 的请求悄悄再跳转一次到高纯净解锁机完成拉流——这也是为什么有时候香港节点居然也能成功打开 ChatGPT 或美区库的原因。
- **YouTube 送中（CN Location Drift）**：某些海外节点的出口 IP，如果长期被大量国内开着「手机位置信息共享给 Google 地图/后台定位服务」的用户连着使用，Google 算法就会发生地理数据库漂移，误认为这个香港/新加坡 IP 其实位于中国大陆境内，导致观看 YouTube 时突然出现「非广告区域异常」或无法开启离线缓存/锁回受限内容。遇到送中只能向机场工单反馈由商家更换新出口 IP，个人客户端无法强行修改。

## 四、服务运营安全与排障常用词汇

- **审计规则（Audit Rules）**：机场在后台针对 BT/PT 磁力种子、SMTP 25 明文发信端口与恶意扫描发起的连接拦截策略，目的是防止连带导致整台海外服务器被机房停机拔线。怎么提前在自己电脑设置规避，详见 [机场审计规则全解析](/resources/airport-audit-rules-explained/)。
- **节点全部 `Timeout`（超时）**：客户端无法收到服务器任何有效回包，常见成因既可能是节点挂了、本地系统时间相差超过 90 秒、没及时更新订阅更换新入口域名，也可能是被本地另一款开着的游戏加速器或残余系统代理规则堵住了口。对照标准排障步骤看 [Timeout 九步法排障清单](/clash/fix-node-timeout-errors/)。
- **机场「拔线 / 清洗 / 跑路」**：如果只是短期几个入口机房被攻击临时切备用入口维护，通常数小时到一两天内客服渠道会有明确通知；但如果出现长期断更、工单全灭、群组禁言同时高额促销多年付套现，就需要立刻按 [失联应急恢复流程](/resources/airport-outage-recovery/) 准备止损与迁移。
